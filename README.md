# 🌟 Telegram Gift Tracker Bot

Бот для отслеживания улучшений (upgrades) подарков в Telegram в реальном времени.

## Возможности

- **Поток улучшений**: опрос контракта Fragment Gift Minter через TonAPI и отправка карточек о свежих улучшениях (< 35 сек).
- **Магазин Telegram**: отслеживание открытия апгрейда, изменения цены, низкого тиража и распродажи подарков (`getAvailableGifts`).
- **Лоты на продажу**: отслеживание новых лотов коллекционных подарков через TonAPI.
- **Фильтры подписчика**: только люди / только каналы, Getgems, только профили, редкость, максимальная цена лота.
- **Подписки и админ-панель**: выдача/отзыв доступа, режим закрытого доступа, рассылка с подтверждением.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения. **Никогда не коммитьте `.env`.**

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `BOT_TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather). |
| `ADMIN_IDS` | да | Telegram ID администраторов через запятую. Пустой список = админ-панель недоступна. |
| `TELEGRAM_API_ID` | нет | MTProto API ID с [my.telegram.org](https://my.telegram.org). Без него профиль-валидация падает на HTML-парсинг. |
| `TELEGRAM_API_HASH` | нет | MTProto API Hash с my.telegram.org. |
| `TELEGRAM_SESSION` | нет | Строка сессии MTProto (для userbot-режима). |
| `TONAPI_KEY` | нет | Ключ [tonapi.io](https://tonapi.io) (повышает лимиты). |
| `MRKT_AUTH_TOKEN` | нет | Токен MRKT API для сбора wallet→username. |
| `CRAFT_POLL_INTERVAL_SEC` | нет | Интервал опроса потока улучшений (по умолчанию 3). |
| `STORE_POLL_INTERVAL_SEC` | нет | Интервал опроса магазина (по умолчанию 30). |
| `MRKT_SYNC_INTERVAL_SEC` | нет | Интервал синхронизации MRKT (по умолчанию 60). |
| `DATA_DIR` | нет | Каталог JSON-базы (по умолчанию `./data`). |
| `PORT` | нет | Порт health-check сервера (по умолчанию 8080). |

## Команды

### Пользовательские

- `/start` — главное меню и статус.
- `/settings` (`/filters`) — фильтры: каналы, Getgems, только профили.
- `/status` — статистика и аптайм.
- `/test` — тестовое уведомление.
- `/help` — справка.

### Администраторские

- `/admin` — интерактивная админ-панель.
- `/sub_toggle` — включить/выключить режим закрытого доступа.
- `/sub_add <id> [дней|forever]` — выдать подписку.
- `/sub_remove <id>` — забрать подписку.
- `/sub_list` — список активных подписок.
- `/broadcast <текст>` — рассылка с обязательным подтверждением.

## Запуск

```bash
npm install
npm run build
npm start
```

Для разработки:

```bash
npm run dev
```

## Docker

```bash
docker build -t starsbot .
docker run --env-file .env -p 8080:8080 starsbot
```

## Деплой на Render

1. Создайте Web Service из репозитория.
2. В панели Render задайте `BOT_TOKEN` и `ADMIN_IDS` (в `render.yaml` для `BOT_TOKEN` стоит `sync: false`, поэтому значение нужно вводить вручную).
3. Остальные переменные можно задать там же.

## Безопасность

- Токен бота, MTProto-сессия и API-ключи живут только в `.env` (в `.gitignore`).
- Если токен когда-либо попадал в git, README или логи — **отзовите его в @BotFather** и выпустите новый.
- Администраторы задаются через `ADMIN_IDS`, а не хардкодом в коде.
